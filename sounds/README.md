# 사운드 파일 넣는 곳

이 폴더에 아래 이름으로 **mp3** 파일을 넣으면 자동으로 재생됩니다.
없는 파일은 그냥 조용히 넘어가요 (브라우저 콘솔에 "아직 없는 파일" 목록이 찍힘).

추천 출처: https://freesound.org (CC0 필터 걸고 검색), https://pixabay.com/sound-effects/

| 파일명 | 용도 | 검색어 예시 |
|---|---|---|
| `ambient_pocha.mp3` | 야장 배경 (루프) — 감성 있게 웅성웅성, 멀리 차 소리 | `outdoor restaurant night ambience`, `street food market night` |
| `ambient_pub.mp3` | 호프 배경 (루프) — 시끄러운 술집 | `crowded bar ambience`, `busy pub walla` |
| `ambient_store.mp3` | 편의점 앞 배경 (루프) — 조용, 귀뚜라미 | `crickets night`, `summer night insects` |
| `chair_scrape.mp3` | 의자 끄는 소리 (크르륵) | `plastic chair drag`, `chair scrape` |
| `clink.mp3` | 짠! 잔 부딪히는 소리 | `glass clink`, `cheers glasses` |
| `pour.mp3` | 술 따르는 소리 | `pouring drink`, `soju pour` |
| `can_open.mp3` | 캔 따는 소리 (편의점 캔맥) | `can open`, `soda can` |
| `sip.mp3` | 홀짝 | `gulp`, `drink sip` |
| `bite.mp3` | 한입 냠 | `eating crunch`, `bite` |
| `serve.mp3` | 음식 내려놓는 소리 | `plate on table` |

| `door_chime.mp3` | 편의점 문 차임 | `store door chime`, `shop bell` |

| `hiccup.mp3` | 많이 취했을 때 딸꾹 | `hiccup` |

배경 루프 3개는 1~3분 길이로, 끝과 시작이 자연스럽게 이어지는 걸 고르면 좋아요.
